# Scan with AI Privacy Policy

**Effective Date:** August 5, 2026

Scan with AI is a Chrome extension that allows you to scan page content and analyze details using Google's Gemini AI.

## 1. Information Handling
- **Page Content:** When you trigger an analysis, the text content of the active tab is sent to Google's Gemini API for processing.
- **API Keys:** You must provide your own Gemini API key. This key is stored securely in your browser's local storage or synced via your Chrome account (`chrome.storage.sync`) and is never shared with us.

## 2. Third-Party Services
This extension uses Google's Generative Language API (Gemini). By using this extension, you agree that your content will be processed by Google according to their [Privacy Policy](https://policies.google.com/privacy) and [API Terms of Service](https://ai.google.dev/terms).

## 3. Data Storage
No data, including page content or analysis results, is stored on our servers. All processing results are displayed locally in the extension popup.
